# wrl-dragon

3D world RL environment powered by the World Labs Marble API and OpenEnv.

## Overview

An agent navigates a 3D world generated by the Marble world model. The environment is text-based: the agent receives 3D coordinates and surroundings as text observations, takes movement actions, and receives rewards based on collisions and exploration.

### Phase 1 — LLM + World Model (current)
- Generate a 3D world via Marble API from a text prompt
- Represent the world as a coordinate grid with obstacles
- OpenEnv environment: agent gets text observations (position, nearby walls/objects), outputs movement actions
- LLM agent navigates using text-based reasoning
- Web dashboard renders the world and agent trajectory in real-time

### Phase 2 — Multimodal Environment
- Capture 2D slices/renders of the 3D world
- Feed visual observations to a VLM via a custom OpenEnv multimodal environment
- Vision-language agent navigates using both text and image observations

## Architecture

```
Marble API ──► World Generation (3D coordinates + obstacles)
                        │
                        ▼
              OpenEnv Environment (text-based)
              ┌─────────────────────────┐
              │  obs: position, walls,  │
              │       nearby objects    │
              │  act: move N/S/E/W/U/D  │
              │  reward: exploration,   │
              │          collision penalty│
              └─────────────────────────┘
                   │              │
                   ▼              ▼
             LLM Agent     Web Dashboard
             (text RL)     (3D viz + logs)
```

## Setup

```bash
# Install uv if needed
curl -LsSf https://astral.sh/uv/install.sh | sh

# Create venv and install deps
uv venv
source .venv/bin/activate
uv pip install -e ".[dev]"

# Set API key
cp .env.example .env
# Edit .env with your WLT_API_KEY from https://platform.worldlabs.ai/
```

## Environment Variables

| Variable | Description |
|----------|-------------|
| `WLT_API_KEY` | World Labs Marble API key |
